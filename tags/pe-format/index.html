      Pe-Format

      Windows PE 파일 구조 및 Win32 API 기반 윈도우 시스템 프로그래밍 기초

      Windows 운영체제에서 실행 가능한 모든 바이너리(EXE, DLL, SYS 등)는 **PE(Portable Executable)**라는 표준 파일 포맷을 따릅니다. 리눅스의 ELF(Executable and Linkable Format)에 대응되는 개념으로, 윈도우 로더(Windows Loader)가 파일을 메모리에 매핑하고 실행하기 위한 메타데이터와 코드가 정밀하게 정의되어 있습니다. 이 글에서는 PE 파일 포맷의 계층적 구조(DOS Header, NT Header, Section Table), 가상 메모리 주소 매핑 원리, 주요 섹션의 메모리 보호 권한, 그리고 Win32 시스템 프로그래밍의 핵심 개념을 정리합니다. 1.
